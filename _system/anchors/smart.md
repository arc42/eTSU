# SMART

A goal-framing standard. Use when a goal warrants full rigor; for a lighter frame
use [[PAM]].

- **Specific** — names a concrete outcome, not a direction.
- **Measurable** — has an indicator that says whether it's met.
- **Achievable** — realistic given known constraints ([[CON-...]]).
- **Relevant** — traces to a stakeholder goal it serves ([[STK-...]]).
- **Time-bound** — has a horizon or deadline.

## Checklist (audit / grill)
- [ ] Outcome is specific, not a vague aspiration.
- [ ] A measure exists and is stated.
- [ ] Achievability is plausible against constraints; if doubtful → [[ISS-...]].
- [ ] Linked to the stakeholder goal it serves.
- [ ] A time frame is given.

A goal missing two or more criteria → raise an Issue proposing the fix.
