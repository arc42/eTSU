# Workshop photo: ten Example Mapping user stories (Req4Arc Linz)

Ten pink index cards in full role-goal-benefit form — six for the artist (check sellings for tax statements; be told of a successful sale; have a print digitized for online presentation; provide artwork to the tour; have pictures displayed to sell them; have art insured against damage), one buyer (a bought painting stays safe on tour so its value remains), one TSU (sign a contract with the artist so obligations are agreed between all parties), one gallery (reserve space so buyers see the work in real life) and one "owner of eTSU", written over a struck-out "gallery owner" (an online portal for artist registration, contacts and interests); an Example Mapping reference card is in the frame, and authorship is unconfirmed.
